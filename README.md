>### Nike website
>A website that displays Nike's major products and iconic collabs while staying loyal to the urban designs.
> ## [Try it out here!](https://nike-website-gilt.vercel.app/)
>
>The site features static HTML pages with a CSS design and vanilla javaScript. It is made up of:
* A section dedicated to show Nike's shoe releases,
* In the shoe section you can see the releases associated to Cnverse and Jordan
* One for the collabs that marks its history,
* In the collabs, there is a collab section only for sports athlete
* When you click on the like button, it sends an email to me saying you like the product
